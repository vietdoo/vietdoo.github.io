# Visual style notes for the next Folio post

The latest Folio AI-agent illustrations use a dark blue-charcoal editorial background, hand-drawn technical diagrams, warm parchment panels, muted slate blue controls, and small amber accents. The visuals combine a human/robot subject with an abstract systems diagram, use wide 16:9 composition, and leave enough negative space for a blog hero crop. Diagram illustrations should be explanatory rather than text-heavy: simple icons, arrows, cards, funnels, shields, keys, and data-flow shapes are preferred over exact paragraphs. Maintain a textured, sketched, technical-editorial look with restrained contrast and no branding or readable UI copy unless specifically required.
